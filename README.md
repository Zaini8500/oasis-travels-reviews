# Oasis Travels — Client Reviews Website

A professional, shareable reviews page for **Oasis Travels** (oasistravels.co.uk), London's Schengen visa appointment specialists.

## What's inside
- Brand-matched design (navy / teal / gold oasis palette) with a recreated Oasis Travels logo (`assets/logo.svg`)
- Hero with the real offer from oasistravels.co.uk: Schengen visa appointments in London, Manchester & Edinburgh for all 29 Schengen countries
- Rating summary, country filter, and review cards
- Services, 4-step "How it works", all 29 Schengen countries, call CTA (020 4617 0987, open 7 days 09:00–17:00)
- A "Leave a review" form (saves to the visitor's browser on this static version)

## ⚠️ Before sharing with clients
The review cards in `script.js` are **sample / illustrative placeholders** (`SAMPLE_REVIEWS`), clearly labelled "Sample" on the page. Replace them with verified client reviews — real names/initials, country and the client's own words — before using this page as proof of service. Swapping them is a 2-minute edit of the `SAMPLE_REVIEWS` list in `script.js`.

## Deploy (Vercel)
Static site — no build step. Import this repo in Vercel, framework preset: **Other / None**, output: root. Or deploy with the Vercel connector/API using `vercel.json` (framework: null).
